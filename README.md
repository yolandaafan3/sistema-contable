# ContaProMax - Proyecto Base

## Descripción

Esta rama contiene la versión base inicial del sistema contable **ContaProMax**, desarrollada como punto de partida para la construcción de las funcionalidades posteriores del proyecto.

El objetivo principal de esta etapa fue establecer una estructura inicial del sistema, preparando los componentes necesarios para continuar con el desarrollo colaborativo mediante ramas independientes.
