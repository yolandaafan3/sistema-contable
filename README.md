# ContaProMax - Diseño e Interfaz del Sistema

## Descripción

Esta rama contiene los cambios relacionados con la **representación visual y diseño de la interfaz del sistema ContaProMax**, enfocándose en mejorar la presentación del sistema, la organización de los elementos visuales y la experiencia del usuario.

El objetivo de esta etapa fue transformar la estructura funcional existente en una interfaz más clara, ordenada y agradable para facilitar la interacción con el sistema.
